Comment ça marche ?

1.Uploadez vos PDFs de cours trading. L'IA les découpe en chunks et les indexe.
2.Envoyez un graphique (capture TradingView, MT4...). Vision LLM décrit la structure.
3.RAG cherche les 5 chunks les plus pertinents de vos cours pour ce pattern.
4.Synthèse finale : pattern + prédiction + niveaux + risques selon VOTRE méthode.

Sans clé API, le mode local fonctionne (heuristique). Pour précision max, ajoutez OPENAI_API_KEY dans .env
